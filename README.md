# تحقيق «الإيمان التام بالنبي ﷺ» لأبي الحسن الحرالي (ت 637 أو 638هـ)

مستودع فريق التحقيق: مواد الدراسة، والنص المخرَّج، وسجل التخريج، وتعريفات الوكلاء البحثيين.

**المشرف:** د. ماجد عبد الله بوشليبي

## البنية

| المسار | المحتوى |
|---|---|
| `CLAUDE.md` | قواعد المشروع الملزمة لكل وكيل |
| `.claude/agents/` | الفريق البحثي: المؤرخ، الباحث التراثي، خبير المخطوطات، المخرِّج، المحرر المدقق، المحكِّم |
| `research/` | مواد الفصول موثقةً بالمصادر المفتوحة فعلاً |
| `edition/` | الملف الأصلي قبل التخريج، والملف المخرَّج (226 حاشية جديدة) |
| `takhrij/` | سجل التخريج (`register.csv` + نسخة Word) |
| `templates/` | بطاقة الوصف العلمي للنسخة |
| `OPEN_QUESTIONS.md` | المسائل المعلّقة ومن يحسمها |

## الفريق ومسار العمل

| المرحلة | الوكيل | المخرَج |

| التأصيل | `historian` · `heritage-researcher` | الفصلان الأول والثاني |

## الحصيلة إلى الآن
- خريطة المحاور والقسم الدراسي (أربعة فصول) — مسودة أولى.
- تخريج 226 حاشية: 30 آية معلَّمة، 32 آية مقتبسة، 161 حديثاً وأثراً وخبراً (113 متحقَّق، 39 مصحَّح، 8 لم يوقف عليها مسندة، 1 بلا إسناد)، 3 حواشٍ إحالية.
- أهم الكشوف: العنوان الثابت «الإيمان التام»؛ نسخة رابعة في برلين (1743)؛ نقول القسطلاني المصرّحة والمنسوجة؛ تصحيف «الحراني» عند الزرقاني ومن تبعه؛ طبعة سابقة سنة 2024 يلزم الاطلاع عليها.
